# Background Catalog

Готовый нативный каталог из 160 фонов: 8 коллекций по 20 композиций. 80 CSS-фонов и 80 Canvas 2D-фонов. Из них 87 анимированных и 73 статичных.

## Запуск

Из папки проекта:

```sh
node server.cjs
```

Откройте http://127.0.0.1:4173. Сервер слушает только loopback-интерфейс. Сборка и установка пакетов не нужны. Основной сайт также работает при открытии `index.html`; для Clipboard API удобнее localhost.

## Возможности

- Восемь категорий, поиск по обоим языкам, совместимые фильтры движения, технологии и тона.
- Отдельные адреса вида `#/background/space-12`; работают прямое открытие и перезагрузка.
- Живой просмотр, пауза, полноэкранный режим, скрытие демонстрационного текста.
- Настройка применимых цветов, скорости и плотности; сброс к авторскому варианту.
- Вкладки HTML/CSS/JavaScript, копирование и самостоятельный HTML-файл без внешних ресурсов.
- Полный RU/EN интерфейс. Первый язык берётся из браузера; выбранный язык хранится в localStorage. Переключение сохраняет текущий фон и настройки. Настройки отдельных фонов живут до перезагрузки страницы.
- Мобильная навигация горизонтально прокручивается, карточки доступны без hover. Есть клавиатурный фокус и управление вкладками стрелками.
- Миниатюры создаются при приближении к экрану; анимируется только карточка под курсором или с фокусом. Canvas учитывает видимость документа и элемента, ResizeObserver и prefers-reduced-motion. Удаление сцены очищает RAF и слушатели.

## Файлы

- `index.html` — входная страница.
- `styles.css` — адаптивный интерфейс и переходы.
- `catalog.js` — 160 именованных композиций, описания на двух языках, палитры и категории.
- `engine.js` — 80 CSS-композиций, 80 Canvas-композиций, общий механизм просмотра/экспорта. Экспорт включает только нужную коллекцию Canvas.
- `app.js` — маршрутизация, интерфейс, локализация, фильтры, настройки, экспорт.
- `server.cjs` — локальный HTTP-сервер на стандартных модулях Node.js.

## Проверки

```sh
node tests/catalog.cjs
```

Для браузерных проверок при работающем сервере:

- `/tests/engine.html` — все 160 экспортов запускаются в независимых iframe; проверяются CSS, Canvas, настройки, пауза, отсутствие внешних запросов. Итог: **160/160**.
- `/tests/lifecycle.html` — детерминированный тест 80 Canvas-анимаций с управляемыми часами и наблюдателями: изменение пикселей, один RAF, пауза/возобновление, скрытие вкладки/сцены, reduced-motion, resize, уничтожение. Итог: **80/80**.
- `/tests/ui.html` — 24 пользовательских сценария в iframe шириной 390 px. Для проверки содержимого копирования и скачивания Clipboard/Blob-интерфейсы перехватываются тестом. Итог: **24/24**.

Визуально проверены галерея, страница фона и мобильный интерфейс в браузере Codex. Тесты не заменяют проверку на каждом физическом устройстве. Fullscreen и системный буфер обмена зависят от возможностей/разрешений браузера; для копирования есть ручной fallback. Переход между миниатюрой и просмотром использует View Transitions при поддержке браузером.

## Добавление фона

Добавьте метаданные в соответствующую коллекцию `NAMES`, композицию в `cssBackground` либо ветку Canvas и обновите параметры доступных настроек. Просмотр и экспорт используют один источник реализации. Не подключайте библиотеки: текущий проект полностью автономен.
